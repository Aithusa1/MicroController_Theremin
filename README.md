# MC Leertaak 2: Theremin

Dit project is onderdeel van het HBO-ICT Microcontroller Cluster (MIC).  
Het doel is om een werkende Theremin te bouwen met een microcontroller, als onderdeel van het Microcontroller Cluster Orkest (MCO).

## Beschrijving

De Theremin is een elektronisch muziekinstrument dat wordt bespeeld zonder fysiek contact.  
In dit project wordt dit principe gesimuleerd met moderne sensoren en componenten.

## Functies

- Toonhoogte wordt bepaald door een afstandssensor (LDR, ultrasoon of ToF)  
- Volume wordt geregeld via een potmeter  
- LCD-scherm toont de toonhoogte  
- 7-segment display geeft de filterinstelling weer  
- Twee knoppen bepalen de filtergrootte  

## Doel

Binnen vier weken een werkende Theremin ontwikkelen die toonhoogte, volume en filtering combineert.  
Het project wordt afgesloten met een auditie waarin het instrument wordt gedemonstreerd.
